## 一、文档说明

### 1.1 文档定位

本文档描述通用 AI 技术底座**管理与观测侧**的产品形态：页面规划、信息展示、操作流程与交互原则。

本文档面向：

1. 架构设计中的管理端模块划分
2. 开发计划中的前端/管理界面任务
3. 与需求文档的验收对照

### 1.2 不在本文档展开的内容

1. UI 视觉稿与高保真原型
2. 接口路径、请求参数与响应结构
3. 前端框架、组件库选型
4. 业务系统（小红书、求职 Agent）的页面设计

---

## 二、产品角色

| 角色 | 说明 | 主要行为 |
|------|------|----------|
| 开发者 / 运维 | 本项目管理与排障人员 | 查看调用日志、分析成本与失败、调整策略配置 |
| 业务系统（调用方） | 小红书、求职 Agent | 通过网关发起调用，不直接使用本产品设计中的「页面」（除嵌入查看链接场景） |

本项目当前为单人或小团队使用，**不区分多租户管理员**；权限模型在后续架构中按需简化。

## 四、核心页面说明

### 4.1 AI 调用日志列表

**目的：** 快速浏览近期所有 AI 调用，支持筛选与进入详情。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 筛选区 | 时间范围、业务类型、项目、调用状态、是否降级、失败类型 |
| 列表区 | 请求编号、时间、业务类型、项目、实际模型、状态、耗时、Token 合计、估算成本、是否降级 |
| 汇总条（可选） | 当前筛选条件下调用次数、成功率、总 Token、总成本 |

**关键操作：**

1. 按条件筛选与重置
2. 点击行进入详情
3. 复制请求编号（便于与业务侧日志关联）

**第一阶段范围：**

- 支持：时间、业务类型、状态、请求编号搜索
- 暂不做：复杂导出、保存筛选方案、实时推送刷新

---

### 4.2 AI 调用日志详情

**目的：** 排查单次调用的完整上下文。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 概要 | 请求编号、时间、业务类型、项目、用户标识、调用状态、总耗时 |
| 模型信息 | 计划模型、实际模型、是否降级、降级链路简述 |
| 消耗 | 输入 Token、输出 Token、合计、估算成本 |
| 重试与失败 | 重试次数、失败类型、失败详情（脱敏） |
| 时间线（可选） | 重试、降级各节点时间点 |

**关键操作：**

1. 返回列表
2. 复制请求编号
3. 若有相邻失败，跳转同业务类型近期失败列表（可选增强）

**展示原则：**

- 失败详情面向人可读，不展示 API Key 等敏感信息
- 降级成功时状态需明确区分于「主模型直接成功」

---

### 4.3 Token 与成本统计

**目的：** 从运营视角了解 AI 消耗趋势与构成。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 时间筛选 | 日 / 周 / 月范围选择 |
| 维度切换 | 按项目、按业务类型、按模型 |
| 汇总卡片 | 总调用次数、总 Token、总估算成本、平均单次成本 |
| 趋势图（可选） | 按日的 Token 或成本折线 |
| 明细表 | 维度下的 breakdown 列表 |

**关键操作：**

1. 切换统计维度与时间范围
2. 从某业务类型钻取到该类型的调用日志列表（带筛选预填）

**第一阶段范围：**

- 支持：日粒度、按项目/业务类型/模型汇总
- 暂不做：自定义报表、PDF 导出、预算预测

---

### 4.4 失败统计

**目的：** 掌握失败结构与高发原因，指导配置与业务优化。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 时间筛选 | 与成本页一致 |
| 失败概览 | 失败次数、失败率、占总调用比例 |
| 按类型分布 | 各失败类型占比（表格或条形） |
| 按模型分布 | 各模型失败次数 |
| 按业务类型分布 | 各业务场景失败次数 |
| 近期典型失败 | 最近 N 条失败记录快捷入口 |

**关键操作：**

1. 点击某失败类型进入日志列表（预填失败类型筛选）
2. 点击某模型查看该模型近期失败详情

**第一阶段范围：**

- 支持：失败类型聚合、按模型/业务类型 breakdown
- 暂不做：自动告警、与外部监控系统联动

---

### 4.5 模型路由与状态

**目的：** 了解当前路由配置与运行时健康状态，辅助判断降级/熔断是否合理。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 路由表（只读为主） | 业务类型 → 主模型 → 备用模型列表 |
| 策略说明 | 低成本优先、高成本限制等文字说明 |
| 模型健康 | 各模型近期成功率、平均耗时、是否熔断中 |
| 降级记录摘要 | 近期降级次数、最常降级路径 |

**关键操作：**

1. 查看配置（第一阶段以只读或配置文件同步展示为主）
2. 从熔断中的模型跳转失败统计

**第一阶段范围：**

- 支持：路由关系展示、熔断状态查看
- 暂不做：可视化拖拽配置路由、热更新无重启

---

### 4.6 系统设置

**目的：** 配置成本防护与查看策略说明。

**主要信息块：**

| 信息块 | 展示内容 |
|--------|----------|
| 成本上限 | 每日全局上限（第一阶段）、当前已用占比 |
| 限流说明 | 全局限流、按业务类型限流阈值说明 |
| 模型单价参考 | 各模型 Token 单价（用于估算，只读展示） |
| 文档链接 | 指向需求文档、架构文档 |

**关键操作：**

1. 修改每日成本上限（需确认）
2. 查看超限后的系统行为说明

**第一阶段范围：**

- 支持：日成本上限配置与当前用量展示
- 暂不做：月上限、用户级上限的完整配置 UI（可在配置文件中维护，页面仅展示说明）

## 五、关键用户流程

### 5.1 排查一次失败调用

```text
1. 进入「调用日志」列表
2. 筛选：状态 = 失败，可选业务类型 / 时间范围
3. 打开目标请求的「详情」
4. 查看：失败类型、失败详情、重试次数、计划/实际模型、是否尝试过降级
5. 若属认证/参数类 → 转系统设置或配置检查
6. 若属限流/超时类 → 查看「失败统计」中同模型是否集中爆发
7. 必要时到业务系统侧用同一请求编号核对业务上下文
```

### 5.2 按业务查看成本

```text
1. 进入「Token 与成本统计」
2. 选择时间范围（如近 7 日）
3. 维度切换为「按业务类型」
4. 查看各业务类型 Token 与成本占比
5. 点击某业务类型 → 跳转日志列表（预填业务类型）
6. 评估是否需要调整路由策略或日成本上限
```

### 5.3 确认降级是否发生

```text
1. 业务侧反馈「结果可用但模型与预期不符」
2. 在日志列表按请求编号搜索
3. 打开详情 → 查看「是否降级」「计划模型 / 实际模型」
4. 若有降级链路 → 到「模型路由与状态」查看主模型是否熔断或高失败率
5. 决定：恢复主模型、调整备用顺序或临时关闭高成本路由
```

## 六、交互与展示原则

| 原则 | 说明 |
|------|------|
| 请求编号贯穿 | 列表、详情、业务侧沟通统一使用同一编号 |
| 失败可读 | 失败类型用中文标签，详情避免原始堆栈直接暴露 |
| 成本透明 | 估算成本旁标注「估算」字样，避免误解为账单 |
| 降级可见 | 降级成功不得与普通过成功混淆展示 |
| 筛选可复用 | 从统计页钻取到日志页时保留筛选条件 |
| 敏感信息脱敏 | 日志详情不展示密钥、完整请求体中的隐私字段 |

## 七、第一阶段：页面与流程范围

> **说明：** 全项目第一阶段 = 本产品设计的第一阶段交付范围。

### 7.1 本阶段交付页面

| 页面 | 交付深度 |
|------|----------|
| 调用日志列表 | 完整筛选 + 列表 + 进入详情 |
| 调用日志详情 | 完整要素展示 |
| Token 与成本统计 | 日粒度 + 三维度汇总 + 钻取日志 |
| 失败统计 | 类型分布 + 钻取日志 |
| 系统设置 | 日成本上限 + 策略说明 |

### 7.2 本阶段简化或延后

| 项 | 处理 |
|----|------|
| 模型路由与状态 | 可先做只读页或合并进系统设置子 Tab |
| 趋势图 | 可用表格代替，图表为增强项 |
| 实时刷新 | 手动刷新即可 |

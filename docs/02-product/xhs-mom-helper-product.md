## 二、目标用户与使用场景

### 2.1 目标用户

个人小红书创作者，尤其是母婴/育儿类内容创作者，自行管理素材并在 App 内发布。

### 2.2 典型场景

| 场景 | 简述 |
|------|------|
| 周末集中创作 | 上传本周照片/短视频 → AI 生成多篇草稿 → 排期到下周 |
| 发布日当天 | 从日历打开待发布草稿 → 导出发布包 → 复制文案、传图 → App 内发布 |
| 发布后复盘 | 录入笔记数据 → 查看 AI 给出的优化建议，指导下一篇选题 |

## 四、核心用户路径

### 4.1 素材 → 生成 → 存草稿

```text
登录 → 素材库上传素材 → 进入 AI 内容生成
→ 选择素材、主题、风格 → 生成标题/正文/标签
→ 人工编辑确认 → 保存草稿
```

### 4.2 草稿 → 排期 → 导出 → 人工发布

```text
草稿箱选择草稿 → 加入内容日历并设置发布时间
→ 到期从日历进入 → 发布包导出页
→ 复制文案、下载素材、按检查清单操作
→ 用户在小红书 App 完成发布 → 更新草稿状态为已发布
```

### 4.3 发布后录入 → 复盘

```text
已发布草稿 → 发布数据复盘页录入指标
→ 查看互动数据与 AI 分析建议 → 沉淀经验，指导下次创作
```

## 五、关键页面说明（一句话）

| 页面 | 目的 |
|------|------|
| 登录页 | 用户进入系统 |
| 首页工作台 | 概览待办：待发布草稿、近期排期、快捷入口 |
| 素材库 | 浏览、筛选、管理全部素材 |
| 素材详情 | 预览单条素材及使用记录 |
| AI 内容生成 | 配置输入并触发生成，编辑后存草稿 |
| 草稿箱 | 按状态管理所有草稿 |
| 草稿详情 | 编辑单篇草稿、变更状态、跳转日历或导出 |
| 内容日历 | 月/周视图查看与调整排期 |
| 发布包导出 | 聚合文案与素材，服务人工发布 |
| 发布数据复盘 | 录入数据并查看分析与建议 |
| AI 调用日志 | 查看本系统 AI 调用记录（底座数据） |
| Token 成本统计 | 查看本系统 AI 消耗 |
| 系统设置 | 账号与创作偏好设置 |

## 六、交互原则

| 原则 | 说明 |
|------|------|
| 人工确认 | AI 生成结果默认需用户编辑或确认后再保存/导出 |
| 一键复制 | 标题、正文、完整文案、标签支持复制，方便粘贴到 App |
| 发布包清晰 | 导出页提供检查清单，减少漏图、漏标签 |
| 状态可见 | 草稿状态（草稿/待发布/已排期/已发布/已归档）在列表与详情一致展示 |
| 不自动发布 | 任何页面不提供「一键发布到小红书」类操作 |
| AI 可追溯 | 生成结果可关联到底座请求编号（便于排障） |

## 七、本系统第一阶段：产品范围

### 7.1 包含页面与能力

| 页面/能力 | 说明 |
|-----------|------|
| 登录页 | 注册登录 |
| 首页工作台 | 简版：素材数量、快捷上传入口 |
| 素材库 / 素材详情 | 上传、列表、预览 |
| AI 调用日志 | 只读查看（底座），验证接入 |
| 系统设置 | 基础账号设置 |

### 7.2 第一阶段不包含的页面

- AI 内容生成（完整流程）→ 阶段二
- 草稿箱、草稿详情 → 阶段二起
- 内容日历 → 阶段三
- 发布包导出 → 阶段四
- 发布数据复盘 → 阶段五

## 八、本系统第一阶段：不做

1. 完整生成向导与多风格选择 UI
2. 日历、发布包、复盘相关页面
3. 小红书账号绑定、扫码登录、自动发布按钮
4. 评论/私信管理界面
5. 多账号切换与团队权限
